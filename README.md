Student Scholarship Management System

A Python-based desktop application developed using Tkinter to simplify scholarship application management. The system allows students to register and apply for scholarships while providing administrators with tools to review, manage, approve, or reject applications.

Project Overview

The Student Scholarship Management System is designed to make the scholarship application process easier and more organised. It provides separate interfaces for students and administrators, with application details stored locally using JSON-based file handling.

Features

Student Module

- Student registration.
- Enter personal and academic details.
- Apply for multiple scholarships.
- View application status.
- Access the student dashboard.

Admin Module

- Secure admin login.
- View all scholarship applications.
- Search student applications.
- Check eligibility.
- Approve or reject applications.
- Delete applications.
- Manage application records.

Eligibility Criteria

The system uses the following sample eligibility conditions:

- Age: 18 years or above.
- Academic marks: 60% or above.
- Annual family income: ₹2,50,000 or below.

Technologies Used

- Programming Language: Python
- GUI Framework: Tkinter
- Data Storage: JSON
- File Handling: Python File Handling

1. Install Python 3.x.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py
